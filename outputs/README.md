# outputs/

Runtime-generated files are written here and are **not committed to Git**.

| Sub-directory      | Contents                                              |
|--------------------|-------------------------------------------------------|
| `frame_features/`  | Per-frame feature `.npy` or `.csv` files (Phase 3)    |
| `sequences/`       | Temporal sequences `X.npy` / `y.npy` (Phase 4)       |
| `visualizations/`  | Annotated frames and debug video clips (Phase 2)      |

These directories are created automatically at runtime.
