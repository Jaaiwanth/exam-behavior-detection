# repeated_left

This directory is intentionally empty in the GitHub repository.

Place your local `.mp4` video clips for the **repeated_left** behaviour here.

Each clip should be approximately 5 seconds long and show a single subject
repeatedly turning their head or gaze to the left while seated as they would be during an exam.

This is treated as a suspicious movement pattern by the evidence engine.

See [`dataset/README.md`](../../../../README.md) for the full dataset instructions.
