# looking_behind

This directory is intentionally empty in the GitHub repository.

Place your local `.mp4` video clips for the **looking_behind** behaviour here.

Each clip should be approximately 5 seconds long and show a single subject
turning to look behind them while seated as they would be during an exam.

This is treated as a suspicious gaze pattern by the evidence engine.

See [`dataset/README.md`](../../../../README.md) for the full dataset instructions.
