# eye_rubbing

This directory is intentionally empty in the GitHub repository.

Place your local `.mp4` video clips for the **eye_rubbing** behaviour here.

Each clip should be approximately 5 seconds long and show a single subject
rubbing or touching their eye area while seated as they would be during an exam.

The hand-to-face proximity and fingertip trajectory are key signals for this class.

See [`dataset/README.md`](../../README.md) for the full dataset instructions.
